## [2.2.0] — 2026-09-24

### Добавлено
- Лимиты частоты запросов: анализ, экспертный разбор, вход в админку.
- Тесты бэкенда (pytest), линтер ruff, prettier для фронтенда, CI на GitHub Actions.
- Метатеги, `<noscript>`, заголовки безопасности в nginx.
- `REAL_IP_FROM`: лимиты по реальному адресу клиента за своим HTTPS-прокси.
- Healthcheck у фронтенда, 41 тест бэкенда (pytest) и 25 фронтенда (vitest), `ruff format` в CI.

### Изменено
- Бэкенд разделён на слои: `core` (алгоритмы), `services` (данные и внешние API), `api` (HTTP).
- «Жюри» переименовано в «экспертный разбор» — в том числе в коде: `/api/expert/*`, `EXPERT_MODELS`
  (`JURY_MODELS` по-прежнему читается).
- Загруженные картинки хранятся в памяти как JPEG 1024 px, а не массив пикселей — в разы меньше памяти.
- Нейросеть грузится при старте приложения, а не при импорте модуля.
- Образ с нейросетью не собирается, если веса не скачались, — вместо тихого перехода на классический движок.
- Тёмная тема описана один раз и следует за системной, пока пользователь не выбрал свою.
- Все ошибки API — в едином формате `{"detail": {"code", "message"}}` по-русски, включая 404, 405 и 500;
  подробности сбоев моделей — только в журнале.
- Сервисы больше не знают про HTTP: чтение загрузок и проверка токена — в `api/deps.py`.
- Сервер принимает те же форматы, что интерфейс: JPG, PNG, WebP.
- Лимит входа в админку считает только неудачные попытки.

### Исправлено
- Замена картинки во время анализа больше не подставляет старую карту внимания.
- Результаты сравнения и полки, пришедшие после изменения набора вариантов, не перезаписывают новый набор.
- Встроенные примеры сопоставляются только по `slug` — пример с таким же названием из админки не затирается.
- Повреждённый `settings.json` откладывается в сторону, сервис стартует с настройками по умолчанию.
- Картинки примеров, не попавшие в настройки из-за лимита, удаляются с диска.
- Узкие картинки («иголки» 32×2000) и больше 40 Мп отклоняются — раньше одна такая съедала 1,7 ГБ памяти.
- Однотонная обложка не даёт NaN; NaN/Infinity в ответах моделей отбрасываются.
- Полка прогоняет всех конкурентов, а не первые семь.
- После перезапуска сервера вкладки сравнения и полки не закрываются, пока картинки загружаются заново.
- Сбой расчёта витрины не повторяется на каждом визите.
- Доступность: клавиатурная навигация по вариантам, дизайнам главной и примерам, подписи у иконок-кнопок.

### Удалено
- Выбор движка из API и технические поля в ответах (`engine`, `engine_title`, `edge_density`, `timing` у анализа).
- Windows-лаунчер вынесен из репозитория.
