# Источники изображений

Варианты обложек (`variant-1.jpg` — `variant-4.jpg`) в ревизии 4 предоставлены владельцем
проекта 1 октября 2026 года. Из присланной подборки выбраны 16 изображений: по четыре для
термоса, кофе, крема и наушников. Изображения подготовлены для сайта в JPEG.

Оставшиеся изображения конкурентов используют исходные фото товаров — [Unsplash](https://unsplash.com), [лицензия Unsplash](https://unsplash.com/license):
бесплатно для любого, в том числе коммерческого, использования. id фото — в `tools/covers/sets.json` (поле `photos`).

В исходном наборе фон вырезан нейросетью rembg, обложки свёрстаны в HTML/CSS скриптом `tools/covers/make_covers.py`.
Бренды на конкурентах вымышленные либо взяты с упаковок на исходных фото.
