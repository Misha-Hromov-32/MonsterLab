# Аудит карточек Wildberries по артикулам: с чего начать магазину

Как проверить каталог через API, разобрать замечания по артикулам и превратить отчёт в очередь задач для редактора и фотографа.

Когда в магазине сотни товаров, команда легко тратит день на одну красивую обложку и пропускает десяток карточек без фото. Для первого аудита составьте перечень действующих артикулов. Включите позиции без фотографий: именно они часто исчезают при ручном отборе примеров.

## Соберите единый список
Для работы через WB API нужен доступ к данным о карточках из категории «Контент». В MonStoreLab откройте [аудит каталога WB](/studio#wb), укажите предназначенный для интеграции токен и запустите проверку. Дождитесь завершения обхода страниц и обработки главных фотографий. Сверяйте количество с действующими карточками продавца; позиции в корзине WB учитывает отдельно.

## Разделите работу между людьми
Артикул без главного снимка отправьте фотографу. Карточку с пустым описанием — редактору. Если встречается рекламная фраза, сначала выясните, в каком поле она стоит. Совпадение в распознанном тексте обложки требует сверки с оригиналом. При ошибке загрузки изображения поставьте повторную проверку: содержимое этого снимка ещё неизвестно.

## Пример записи для команды
Условный артикул T-500 обозначает термос объёмом 500 мл. В названии есть слова «хит продаж», а в описании отсутствует информация о материале колбы. Задача редактору — удалить оценочное суждение, сверить материал со спецификацией и внести подтверждённое значение. Укажите артикул и ожидаемый результат, чтобы другой сотрудник мог проверить правку.

## Сравните результат после обновления
Выгрузите отчёт, сохраните дату проверки и выдайте команде список ответственных. После внесения изменений в кабинете WB запустите новый аудит. Сопоставляйте результаты по артикулу WB: названия могут измениться, а одинаковое имя нередко встречается у нескольких цветов и комплектаций. Проверьте отдельно незавершённые проверки и карточки, у которых сохранилось прежнее замечание. [Документация WB API по карточкам товаров](https://dev.wildberries.ru/docs/openapi/work-with-products)
