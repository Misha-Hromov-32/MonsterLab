# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено
- **Очередь задач** для всего тяжёлого: нейросеть внимания, языковые модели, генерация обложек, браузер для WB.
  Своя полоса и число исполнителей для каждого вида работы (`QUEUE_*`), приоритет по тарифу, ограничение
  задач на покупателя, повторная проверка квоты перед запуском. Покупатель видит своё место в очереди
  и оценку ожидания, админ — вкладку «Очередь» с загрузкой полос и текущими задачами.
  API: тяжёлые ручки отвечают `202 {"job"}`, статус — `GET /api/jobs/{id}`; `X-Wait: 1` — синхронный ответ.
- **Визуальный разбор «как арт-директор»** вместо прежнего экспертного: общее впечатление, стиль и исполнение,
  какой сегмент и аудиторию считывает обложка и совпадает ли это с позиционированием, роль и польза каждой
  надписи, порядок чтения, вид рядом с конкурентами с полки, что сильного (не трогать) и что улучшить.
  Модель — `VISUAL_MODEL` (Claude Sonnet 5.5), при сбое — запасная из `EXPERT_MODELS`.
  Новое поле «Бренд и позиционирование» в данных о товаре.
- **Тарифы**: разовый демо-доступ после подтверждения почты и несколько платных тарифов с квотами на период
  оплаты (по умолчанию «Старт», «Про», «Агентство»); квоты считаются для всех функций — проверка обложки,
  тест полки, визуальный разбор, выбор покупателя, улучшенная обложка, подбор конкурентов. Тарифы и квоты
  правятся в админке. Одноразовые почтовые ящики при регистрации не принимаются.
- **Статистика в админке**: воронка «визиты → регистрации → подтверждения → запуски → оплаты» за 30 дней,
  выручка, платящие по тарифам, запуски каждой функции (сегодня / 7 / 30 дней / всего) с оценкой трат
  на нейросети, графики по дням, последние платежи и покупатели с поиском.
- **Вход обязателен**: проверка обложек, тест полки и примеры — только для зарегистрированных,
  без входа открыты главная и тарифы.
- **Подтверждение почты** при регистрации: HTML-письмо в стиле сайта со ссылкой на 24 часа,
  повторная отправка не чаще раза в минуту. Отправка — SMTP (`SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`…).
- **Восстановление пароля** по ссылке из письма; новый пароль отзывает все прежние входы.
- **Правила сервиса** на странице `/legal`: пользовательское соглашение, политика обработки персональных
  данных и отдельное согласие на обработку. При регистрации — две обязательные галочки, сервер хранит
  время согласий и редакцию правил. Реквизиты оператора — `LEGAL_OPERATOR`, `LEGAL_EMAIL`.
- **Шифрование данных покупателей**: пароли — Argon2id с «перцем», email — AES-256-GCM
  со «слепым» индексом HMAC-SHA256, ключи — из `MASTER_KEY`.
- **Улучшенная обложка**: нейросеть перерисовывает обложку по выводам разбора, результат можно сразу
  добавить вариантом и сравнить.
- **Подбор конкурентов с Wildberries**: топ выдачи по поисковому запросу — сразу в тест полки.
- **Вероятность выбора** в экспертном сравнении: шанс, что покупатель выберет вариант, в процентах.
- **Аккаунты и подписка**: вход по email, бесплатный и платный тариф с дневными лимитами платных
  функций, оплата через ЮKassa (включается ключами `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`).
- Результаты примеров считаются заранее и хранятся в SQLite (`examples.sqlite` в томе `data`):
  разбор обложек, тест полки и витрина открываются мгновенно, без нейросети на каждый показ.
  После правок в админке или новой ревизии примеров всё пересчитывается в фоне.

### Исправлено
- Индекс заметности откалиброван на инфографике маркетплейсов: товар, заголовок и 3–5 плашек — норма,
  а не «визуальный перегруз»; подсказки без шаблонного «уберите плашки». Индекс — только про внимание,
  о стиле и смысле — визуальный разбор.
- Gemini 2.5 в экспертном разборе и сравнении: «размышления» модели съедали лимит токенов, и ответ
  обрывался посреди JSON. Теперь у запроса есть запас на размышления.
- Токен покупателя, чей email не расшифровывается (сменили `MASTER_KEY`), больше не роняет запрос
  ошибкой 500 — покупателя просят войти заново; подпись токена проверяется до расшифровки данных.

### Изменено
- Сняты лимиты памяти контейнера (`BACKEND_MEM_LIMIT` больше не используется): нагрузку держит очередь.
- Дешевле запросы к моделям: выбор покупателя — без «размышлений» Gemini (в 7 раз дешевле), улучшенная
  обложка — в качестве `IMAGE_QUALITY=medium` (в 3,7 раза дешевле и вдвое быстрее).
- Метрика «Ясность» переименована в «Лёгкость восприятия» (ключ `ease` в API).
- Зависимости бэкенда: FastAPI 0.141, NumPy 2.4, OpenCV 5, Pillow 12, SciPy 1.17; ruff 0.16, pytest 9.
- GitHub Actions v7; Dependabot группирует обновления и не предлагает несовместимые (Python 3.14, TypeScript 7).
- README стал короче: подробности — в `docs/`, настройки — в [docs/configuration.md](configuration.md).

## [2.2.0] — 2026-09-24

### Добавлено
- Лимиты частоты запросов: анализ, экспертный разбор, вход в админку.
- Тесты бэкенда (pytest), линтер ruff, prettier для фронтенда, CI на GitHub Actions.
- Метатеги, `<noscript>`, заголовки безопасности в nginx.
- `REAL_IP_FROM`: лимиты по реальному адресу клиента за своим HTTPS-прокси.
- Healthcheck у фронтенда, 41 тест бэкенда (pytest) и 25 фронтенда (vitest), `ruff format` в CI.

### Изменено
- Бэкенд разделён на слои: `core` (алгоритмы), `services` (данные и внешние API), `api` (HTTP).
- «Жюри» переименовано в «экспертный разбор» — в том числе в коде: `/api/expert/*`, `EXPERT_MODELS`
  (`JURY_MODELS` по-прежнему читается).
- Загруженные картинки хранятся в памяти как JPEG 1024 px, а не массив пикселей — в разы меньше памяти.
- Нейросеть грузится при старте приложения, а не при импорте модуля.
- Образ с нейросетью не собирается, если веса не скачались, — вместо тихого перехода на классический движок.
- Тёмная тема описана один раз и следует за системной, пока пользователь не выбрал свою.
- Все ошибки API — в едином формате `{"detail": {"code", "message"}}` по-русски, включая 404, 405 и 500;
  подробности сбоев моделей — только в журнале.
- Сервисы больше не знают про HTTP: чтение загрузок и проверка токена — в `api/deps.py`.
- Сервер принимает те же форматы, что интерфейс: JPG, PNG, WebP.
- Лимит входа в админку считает только неудачные попытки.

### Исправлено
- Замена картинки во время анализа больше не подставляет старую карту внимания.
- Результаты сравнения и полки, пришедшие после изменения набора вариантов, не перезаписывают новый набор.
- Встроенные примеры сопоставляются только по `slug` — пример с таким же названием из админки не затирается.
- Повреждённый `settings.json` откладывается в сторону, сервис стартует с настройками по умолчанию.
- Картинки примеров, не попавшие в настройки из-за лимита, удаляются с диска.
- Узкие картинки («иголки» 32×2000) и больше 40 Мп отклоняются — раньше одна такая съедала 1,7 ГБ памяти.
- Однотонная обложка не даёт NaN; NaN/Infinity в ответах моделей отбрасываются.
- Полка прогоняет всех конкурентов, а не первые семь.
- После перезапуска сервера вкладки сравнения и полки не закрываются, пока картинки загружаются заново.
- Сбой расчёта витрины не повторяется на каждом визите.
- Доступность: клавиатурная навигация по вариантам, дизайнам главной и примерам, подписи у иконок-кнопок.

### Удалено
- Выбор движка из API и технические поля в ответах (`engine`, `engine_title`, `edge_density`, `timing` у анализа).
- Windows-лаунчер вынесен из репозитория.
